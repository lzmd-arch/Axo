# 预注册：中文金标准上的召回重排 v1（2026-11-05）

**状态：判据先落盘。**

## 问题

LoCoMo 英文上，第二段重排把 hit@5 从 0.493 抬到 0.538（启发式）/ 0.654（学习版）。
**中文是否成立？** 这一轮只测中文金标准语料 `benchmarks/gold/`，不改第一段、不改阈值。

## 口径

- 语料：`benchmarks/gold/`，208 条记忆 / 85 条查询；两份 JSONL 的 sha256 见
  `benchmarks/gold/freeze.json`（memories `de0c66cf…`，queries `300afc50…`）。
- 第一段：`RecallConfig()` 出厂默认（`max_items=8`、`candidate_limit=200`，产品门槛
  `min_score=0.20`）；时间通道按语料自带的 `created_at`。
- 两个嵌入臂：
  - **bge-zh 主臂**：随包 `bge-small-zh-v1.5`（本地 ONNX，产品默认路径）；
  - **纯词法副臂**：无嵌入，CI 可复现。
- 重排只改排序（阈值之后、MMR/预算之前）；D 去留、预算、条数均不变。
- 指标用**产品选择后**的注入序列（MMR + 预算 + `max_items=8`），不是候选 top-k：
  hit@1/3/5/8、证据覆盖@8、MRR、误注入率、`no_answer` 平均注入条数；按 category 分列。
- 候选覆盖@200：证据在候选池里的比例（分母 = 全部查询的 expect 条数）。

## 两条臂

### H. 启发式（主臂，无训练）

沿用 LoCoMo 预注册里写死的权重：

```
score = 0.60*fused + 0.15*bm25_norm + 0.10*number_overlap
      + 0.10*entity_overlap + 0.05*rank_reciprocal
```

`bm25_norm` 在本查询候选内 min-max。**看到结果后不改权重。**

### L. 学习版（副臂，探索）

线性 RankNet，特征同 LoCoMo 的 11 项；**5 折按查询 id 的 CRC32 分折**，
每折在 68 条查询上训练、17 条上评测；池化各折留出结果。85 条查询很小，
这一臂只作为探索，不作为产品门槛。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **Z0** | 候选里有证据 | 候选覆盖@200 ≥ **0.95** |
| **Z1** | 启发式把证据往前挪 | bge 主臂 hit@5 ≥ baseline + **0.03** |
| **Z2** | 不用误注入换命中 | 误注入率 ≤ baseline + **0.02**，且 `no_answer` 平均注入 ≤ baseline + **0.25** |
| **Z3** | 难例不倒退 | `name_number` hit@1 不低于 baseline；`paraphrase` hit@5 不低于 baseline − **0.10** |
| **Z4** | 学习版不差于启发式 | 5 折池化 hit@5 ≥ 启发式 − **0.02**（探索性） |
| **Z5** | 成本 | 单查询重排 < **10 ms**（隔离微基准，缓存热） |

Z0 不过是无效实验；Z1 不过是中文不成立，**不接线、不改默认**。

## 不做的事

- 不调第一段嵌入/阈值/权重；不按类别训练；
- 不在评测折上调启发式权重；
- 不把 LoCoMo 的英文学习版权重直接拿来当中文结论（只作为对照）；
- 不因为一次不过就换折数/换特征再试——另写预注册。

## 通过之后

1. 启发式在中文金标准上过 Z1–Z3、Z5 → 产品设置里可作为「启发式」档的**中文依据**；

3. 学习版只有 85 条查询，最多算探索；中文更大语料要另建。
