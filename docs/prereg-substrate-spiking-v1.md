# 预注册：基质 W 的脉冲动力学（v1，2026-11-01）

**状态：先写判据，代码未动。** 这是用户要求的“两者都做、分开验”里的第二件。

## 要回答的问题

基质 W 现在做的是**线性一步补全**（`W p = Aᵀ(A p)`）。如果把同一份关联码喂给一群
ALIF 神经元跑若干步，**补全的 top-1 准确率是否更好**？

## 判据（跑之前写死）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| S1 | 脉冲群体在 substrate 语料（200 条记忆 / 40 条查询）上的补全 top-1 | **≥ 线性一步 +5 个百分点** |
| S2 | 线性一步**不得**反过来领先脉冲 5 个百分点 | 双向都看 |
| S3 | 开启后单次补全延迟 | **< +20 ms**（相对线性一步） |

任一条不达即记为负结果，默认保持关闭。

## 怎么搭（跑之前定死）

- 神经元：`biosnn_bus.AdaptiveMembrane`，群体规模 **512**（与另一条试验同口径），
  参数取研究层默认（`tau=20, tau_adaptation=500, threshold=0.62, beta=0.07, n_refractory=2`）。
- 输入：关联码（4096 位、k=64）经固定随机投影到 512 维作为电流，**种子固定**。
- 时间：`T=10` 步；读出取最后一步的发放率。
- 开关：`SubstrateConfig.spiking: bool = False`，默认关；关着时行为与现在**逐字节相同**。
- 种子：投影与任何随机初始化固定种子，跑 **10 个种子**，报中位数与区间。

## 跑之前的预期

**预期是失败。** 依据：同一族试验（512 个 ALIF 做召回打分）已经量出 hit@1 0.024 vs
基线 0.259（`BioSNN-Plug/research/spiking_512/`）；而基质补全比召回更依赖精确的点积
几何。写下来是为了防止事后把失败解释成“没调好”。

## 与那条负结果的区别

`research/spiking_512` 试的是**用发放率替代余弦打分**；这里试的是**用群体动力学做补全的
迭代**——后者理论上可能有增益（吸引子动力学），所以值得单独验一次，而不是拿旧结论直接否掉。
