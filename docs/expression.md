# 分离表达层（实验）

> 目标：**后端只决定"说什么"，终端侧决定"怎么说"。** 换模型时，用户听到的语气不变。
>
> 状态：**Phase 1/2 已落地，默认关闭；SEL 脉冲路径已收口（ADR-0034）。** 设计稿见桌面 `axo-expression-layer-architecture.md`
> （v1.0，2026-11-02）——本文件记的是"落地时改了什么、为什么"，不是那份稿子的复述。

## 这一版做了什么

| 那份稿子 | 这一版 | 为什么 |
|---|---|---|
| 后端直接输出 SIR（`<think>` + `<content>`） | **能解析，但默认不要求主模型这样输出** | 把主对话的格式改成 `<think>` 会同时撞上两件已有的事：工具调用与"思考吃额度 ⇒ 空回复"。生产路径走 `derive()`（从普通文本抽 SIR），SIR-first 留给"后端确认支持"之后 |
| 本地 Qwen2-0.5B INT4 ONNX | **Ollama 里的小模型**（默认 `qwen2.5:0.5b`） | 本仓没有 transformers/optimum 那套文本生成栈；再引 `onnxruntime` 只省不了什么。随包的 llama.cpp 只能同时跑一个模型（主对话那个），另起一个要第二份显存。Ollama 是现成的第二模型入口 |
| 所有回复都走表达层 | **只走不带工具的那一轮（闲聊语域）** | 任务轮中间几轮的"边想边说"与工具结果是一体的，重写它会把"她做了什么"与"她怎么说"混在一起。Phase 2 再考虑只重写收尾那一轮 |
| 流式回复 | **打开后这一轮先不显示，渲染完再出** | 事实核对必须发生在显示之前；先流出去的文字收不回来。代价是首字更晚，这一条写在设置页与下面"代价"里 |
| 事实靠提示词"必须保留" | **提示词 + 渲染后逐条核对** | 0.5B 尺寸的模型写顺了手照样会改数。核对不过就整段退回草稿——宁可语气不统一，不让一个数被悄悄改掉 |

## 结构

```
主模型（后端，任意）
   │  草稿文本
   ▼
axo.expression.sir.parse()        有 <think> 就解析，没有就 derive()
   │  SIR（意图 / 要点 / 语气 / 长度 / 必须保留的事实 / 草稿）
   ▼
axo.expression.layer.ExpressionLayer.render()
   │  本地小模型按人格重写
   ▼
核对：facts 全在？问句还是问句？空输出？
   ├─ 通过 → styled
   └─ 不过 → draft（原样草稿）+ 一句原因
```

* `src/axo/expression/sir.py` —— 纯层：解析、降级、事实抽取与核对、风格指标；
* `src/axo/expression/layer.py` —— 一次渲染，**不抛异常**，失败一律退回草稿；
* `src/axo/ui/expression_worker.py` —— 把渲染挪到工作线程；
* `src/axo/ui/main_window.py` —— 只接在闲聊轮：增量先攒起来，渲染完才显示。

关掉时（默认）主窗口走原来的直连流式路径，代码一个分支都不进。

## 验收判据（Phase 1）

1. **关闭时逐位不变**：`tests/test_ui_expression_wire.py` 断言关着的那条连接仍在；
   全量测试绿。
2. **失败开放**：渲染后端不可用、输出为空、中途停止、丢事实、问句变陈述句——
   一律退回草稿且**必定收尾**（单测覆盖五条）。
3. **事实保真 ≥95%**：30 条带数字/URL/路径的样本，渲染后 `facts` 全在。**已跑：30/30**
   ——用 30 条合成草稿与 0.5B GGUF 实测。
4. **额外延迟 p50 ≤ 3 s**（0.5B CPU）。本机用 `qwen3-4b` 做的管线实测（4 条样本、
   预热后）：0.08–1.82 s；首条冷启动曾达 18.9 s。**这不是 0.5B 的数**。
5. **风格一致性**：同一问题在三个后端上，开启表达层后 `style_signature` 的句长/
   感叹号/连接词离散度应下降。**已跑（两后端）：0.92×，未达 ≤0.5×；第三后端缺。**

第 3 条过、第 5 条不过；这一批的结论只有"管线通了、失败路径可靠"，**不是"语气统一了"**。

## 实测记下的一件事

2026-11-03 用 `qwen3-4b` 跑管线时，第一版渲染**输出为空**，原因不是模型不会写，而是
思考与正文共用输出额度（256 token 全花在思考上）。请求里补 `think: false` 之后正常。
同一天还测到：渲染把"…说说吗？"的句末问号吃掉了——字都对、语气全变。前者是后端
参数（`ExpressionLayer(think=False)`），后者是核对层的一条独立判据（问句必须仍是问句）。

## Phase 2：模板优先（2026-11-03，默认关）

- `src/axo/expression/templates.py`：模板库（JSONL 可加载）+ 内置一组**中性形状**
  （拒绝 / 短回答 / 问句 / 安慰开场）。槽位只取 SIR 的 `key_point:i` / `fact:i` /
  `facts`，**不新增信息**；未知槽位在加载时拒绝。
- `src/axo/expression/mix.py`：`MixedRenderer` = 模板命中 → 模型 → 草稿。命中模板时
  **不调用模型**；命中之后仍过 `facts_preserved` 与问句检查，不过就当没命中。
- 设置：`expression/templates`，默认关；「工具」页表达层那组多一格「模板优先」。
- 测试：`tests/test_expression_templates.py` 22 条（匹配、填槽、事实、问句、命中不调模型、
  加载校验）。

## 2026-11-03：0.5B 模型与三项验收（GGUF + 内置 llama.cpp）

`ollama pull qwen2.5:0.5b` 被代理的假 IP 挡住（R2 域名解析成 `198.18.0.38`，Ollama
拒绝非公网地址），改走 **Hugging Face GGUF + 随包 llama.cpp**：
`D:\AxoData\models\qwen2.5-0.5b-instruct-q4_k_m.gguf`（491,400,032 字节），
`LlamaServerRuntime(context=4096, gpu_layers=0)` 起一个 CPU 实例做测量。**产品路径没有
接这个后端**——`_expression_backend` 仍只构造 Ollama；这一批是实验测量。

Phase 1 遗留三项（30 条合成草稿，qwen2.5-0.5b 渲染）：

| 判据 | 结果 | 判定 |
| :--- | :--- | :--- |
| 事实保真 | styled 30/30，事实 30/30 | **过**（≥95%） |
| 延迟（CPU） | p50 **0.30 s**、p90 0.59 s | **过**（≤3 s） |
| 三后端风格离散 | 只有两后端（qwen3-4b vs 0.5B）：raw L1 均值 1.50 → styled 1.38（0.92×） | **不过**（要求 ≤0.5×；第三后端缺，云端 key 未读） |

**Phase 2 教师 T1–T5（60 条合成 SIR：5 意图 × 3 语气 × 2 长度 × 有/无事实）**：

| 判据 | 初测（0.5B） | 扩展后（0.5B） | 扩展后（1.5B） | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| T1 模板命中率 | 17/60 = 28% | **35/60 = 58%** | 35/60 = 58% | **过**（≥40%） |
| T2 事实保留 | 0 丢 | 0 丢 | 0 丢 | **过** |
| T3 延迟 | 模板 ≈0 ms；模型 p50 0.30 s | 同左 | 模型 p50 **1.11 s** | **过**（≤1.5 s） |
| T4 风格离散比（full） | 1.02× | 0.88×（temp 0） | **0.76×**（temp 0） | **不过**（≤0.5×） |
| T4（仅风格标记） | — | 0.57× | **0.50×** | 边界，未低于 0.5 |
| T5 问句保留 | 0 违例 | 0 违例 | 0 违例 | **过** |

**两次试法都记在这里**：

1. **扩模板**（emotion/action 三语气、带事实的回答）把 T1 从 28% 拉到 58%。扩的时候
   抓到一个真 bug：`TemplateBank.render` 以前只试哈希选中的那一条，而"不带事实"的
   短回答模板可能先命中、把正确的那条挡住；现在按哈希定起点逐条试到过检查为止
   （确定性不变）。
2. **换更强的渲染器**（1.5B GGUF，CPU）把 T4 从 0.88× 拉到 0.76×（仅风格标记 0.50×），
   但预注册的 full 判据仍未过。测量改为 `temperature=0`，因为 0.7 下同一段 SIR 两次
   渲染不同、比值会抖（0.72–0.90）。

**结论：Phase 2 作为教师仍不达标（T4）。** 按预注册，**P3 不启动**。下一步是用户决定：
要不要再上 3B（约 2 GB，CPU 延迟预计 2–3 s，收益可能仍不够），或者提修正案把 T4 的
口径改成"仅风格标记"（0.50×），而不是在跑完之后悄悄换尺子。模板优先继续默认关。

## 2026-11-03 续：3B 试完、回显 bug、P3 数据

- **3B GGUF（CPU）更差**：T4 全向量 0.99×、仅风格标记 0.75×、模型路径 p50 **5.94 s**
  （超过 3 s 上限）。1.5B 仍是这批里最好的（0.76× / 0.50× / 1.11 s）。
- **提示词回显是一个真 bug**：0.5B 偶尔不写正文、把渲染提示词整段抄回来；它**能通过
  事实核对**（事实确实在里面），所以会被当成正文显示。`ExpressionLayer` 现在命中两个
  以上提示词字段名就退回草稿（生产路径同样生效），带单测。这是在 P3 生成数据时抓到的。
- **P3 教师数据**：教师降级为 Phase 1（用户拍板），数据在
  `D:\AxoData\sel\pairs\`（不入库）。第一轮 400 请求 → 去重 101 条（D1 不过）；
  修正之一（意图配比/唯一序号/回显检测/拒绝族上限）后 272 条（仍 <300）；修正之二换
  1.5B 教师，第三轮进行中。预注册与两次修正都在 `research/sel/`。

## 2026-11-04 决策：SEL 脉冲路径停止，Phase 2 为回退

- SEL 的概念（换后端模型时语气不变）仍然成立，但 **TI-LIF + CWSSA + SSM + KD** 这条
  路径已停止（BioSNN-Plug ADR-0034）；P5 在线 R-STDP 不启动。
- **产品不接脉冲表达层**。Phase 2（模板 + 模型混合渲染）保留为回退路径，当前仍默认关；
  T4 未过，文档与界面不得声称"语气已统一"。
- P3 的 391 对教师数据可转作 SFT 语料，**不做蒸馏**；另写数据使用说明与训练预注册，
  数据仍不入库。
- ALIF-only SEL 是远期备选，现在不写预注册、不分配算力。
