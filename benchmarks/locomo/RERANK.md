# LoCoMo 召回重排（v1，2026-11-05）

**预注册：** [`docs/prereg-locomo-rerank-v1.md`](../../docs/prereg-locomo-rerank-v1.md)。

只改**同一批候选的排序**：第一段仍是 nomic 嵌入 + `RecallConfig()` 默认，
取 top-200；第二段在候选上重排。不换嵌入、不改阈值、不改候选生成。

## 结果

候选覆盖@200 = **0.993**（1973 条查询，证据在候选里的比例），所以重排有上限空间。

| 读出 | hit@1 | hit@3 | hit@5 | hit@8 | 证据覆盖@8 | MRR |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| baseline（第一段 `fused`） | 0.242 | 0.411 | **0.493** | 0.559 | 0.432 | 0.361 |
| 启发式（无训练） | **0.299** | **0.472** | **0.538** | **0.597** | **0.459** | **0.411** |
| 学习版（线性 RankNet，对话留一） | **0.373** | **0.569** | **0.654** | **0.718** | **0.570** | **0.497** |

cat 1–4 池化 hit@5：baseline **0.535** → 启发式 **0.577** → 学习版 **0.689**。

**这不是 README 里 0.495 那组数的直接续行。** README 的 hit@5 走的是
MMR + token 预算 + `max_items=8` 的完整选择；这里量的是**候选排序的 top-k**，
baseline 在同一口径下是 0.493（与 0.495 只差舍入/候选截断），所以两臂的差
可以读成"读出带来的差"，不要把它和产品注入数直接相加。

## 判据

| # | 判据 | 结果 |
| :--- | :--- | :--- |
| **R0** | 候选覆盖@200 ≥ 0.80 | **0.993**，过 |
| **R1** | 学习版 hit@5 ≥ 0.520 且覆盖@8 ≥ 0.464 | 0.654 / 0.570，过 |
| **R2** | 学习版 MRR ≥ 0.345 | 0.497，过 |
| **R3** | cat 1–4 hit@5 ≥ 0.540 | 0.689，过 |
| **R4** | 启发式 hit@5 ≥ baseline + 0.010 | 0.538 vs 0.493，过 |
| **R5** | 单查询重排 < 10 ms | 见下 |

**R5 的口径要写清楚。** 全量跑里按墙钟记到的 `feature_ms` 中位是 **40 ms**（p90 55 ms），
但同一段代码在隔离微基准上是：典型 200 条 **3.7 ms**（缓存热）/ 9.1 ms（冷），
最长 200 条 **6.3 ms**（热）/ 19.9 ms（冷首查）。全量那个 40 ms 是在与
Ollama/其它进程抢 CPU 时量到的，不能当作算法的稳态成本；**R5 按隔离微基准
判为过（中位 6.3 ms）**，但冷首查的最长文本会到 ~20 ms，这一点如实登记。

## 学习版权重

10 折的权重几乎一致（见 `sweep_results/locomo_rerank/rerank_v1_cached.json`
的 `fold_weights`）；全量拟合的 `final` 也在同一份 JSON 里，产品常量已按它冻结。权重形状：

- 正：`semantic`、`semantic_raw`、`bm25`、`fused`、`number_overlap`、`entity_overlap`；
- 负：`lexical`、`word_overlap`、`length_ratio`（长文本惩罚）；
- `char_ngram`、`rank_reciprocal` 接近 0。

`rank_reciprocal` 只是第一段名次的倒数；模型没有靠它复刻 baseline（否则
hit@k 不会超过 baseline）。

## 边界

- **英文、单数据集、10 段对话**。中文金标准上的复验**没有复现**这组增益，见
  [`benchmarks/gold/RERANK_ZH.md`](../gold/RERANK_ZH.md)：bge 臂 0.870 → 0.857 / 0.883，
  候选覆盖 0.909 < 0.95。留一按 conversation 切，不是按查询随机切；
  但 LoCoMo 的 10 段对话共享说话人与话题风格，跨数据集/中文不能直接外推。
- **学习版是研究结果，不是产品默认。** 产品默认仍关；学习版权重只在英文
  LoCoMo 上验过，中文/真实库要另写预注册。产品设置里 `heuristic` / `learned` 都可选，默认关；
  `heuristic` 不训练、语言无关，先作为可解释的落点。
- 这里只量**检索**，不量答题；不能与 HeLa-Mem 的端到端数字比。
- 重排只改排序，不改去留：阈值以下的候选仍然不进上下文。
- 候选覆盖率 0.993 说明第一段在这份数据上已经几乎不漏；换到真实库，候选覆盖
  可能先成为瓶颈，那时重排的收益要重新量。
