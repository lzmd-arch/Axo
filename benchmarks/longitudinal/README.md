# 纵向记忆基准 v0（合成年龄）

**目的**：把「记忆质量随积累月数变化」变成可测的仪表。v0 不等真实月份——金标准语料的
时间戳是冻结的（`CREATED_AT`），召回按传入的 `now` 结算惰性衰减，所以把 `now` 往后拨
0/1/3/6/12 个月，就能量到**同一份库在不同年龄下的召回质量**。

**这不是真实积累**：它是「如果这些记忆真的放了 N 个月」的模拟。v0 建立的是仪表与口径，
不是纵向结论。

## 运行

```bash
.venv/Scripts/python.exe -m axo.bench.longitudinal --out benchmarks/longitudinal/$(date +%F).json
```

每月跑一次，同一金标准、同一命令，快照逐月比较。`kind` 字段写明 `synthetic ages`；
脚本会记录 `git_commit` 与语料 sha256，防止换语料后比较。

## v0 结果（2026-10-29，词法通道）

| 年龄（月） | hit@1 | hit@3 | recall@3 | MRR | false injection |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 0.896 | 0.922 | 0.922 | 0.910 | 0.868 |
| 1 | 0.896 | 0.922 | 0.922 | 0.909 | 0.868 |
| 3 | 0.896 | 0.909 | 0.909 | 0.907 | 0.868 |
| 6 | 0.896 | 0.896 | 0.896 | 0.905 | 0.868 |
| 12 | 0.818 | 0.818 | 0.818 | 0.827 | 0.878 |

读法：hit@1 在 6 个月内持平、12 个月掉 **7.8 个百分点**；MRR 单调下降（0.910 → 0.827）。
误注入率基本不变。这说明惰性衰减在一年尺度上确实开始吃掉召回——**但只到词法通道、
单语料、合成年龄**。

## 边界

- 只量词法通道（无嵌入）；语义通道需要 embedder，留给 v1；
- 合成年龄靠 `now` 偏移，不模拟真实访问/巩固历史（access_count、reinforce_count 不变）；
- 金标准语料冻结，换语料后不可比；
- v0 不设通过阈值——它只记录趋势，避免把「第一年没掉多少」写成能力。
